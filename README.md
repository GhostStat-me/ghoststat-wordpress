# GhostStat Analytics for WordPress

Cookieless visitor intelligence: see who visits, why they buy and why they leave, right in WordPress. No cookie
banner needed. WordPress 6.3+, PHP 7.4+. Version 1.2.0.

The plugin is in the WordPress plugin directory as
[GhostStat Analytics](https://wordpress.org/plugins/ghoststat-analytics/) — install it from **Plugins → Add Plugin**
to get automatic updates. This repository has the same code.

## Install from here

1. Download `ghoststat-analytics-1.2.0.zip` from [Releases](https://github.com/GhostStat-me/ghoststat-wordpress/releases).
2. In WordPress: **Plugins → Add Plugin → Upload Plugin**, choose the zip, **Install Now**, **Activate Plugin**.
3. **Settings → GhostStat**: paste your site key (GhostStat → Site settings → Tracking) and **Save Changes**.

Optional: an API key (GhostStat → Site settings → API keys) shows your numbers inside WordPress, and a report key
(GhostStat → Software Development → Connect) reports plugins, themes and updates to GhostStat.

Everything else — what is sent, external services, the full changelog — is in
[ghoststat-analytics/readme.txt](ghoststat-analytics/readme.txt).
